# neo POCS V2 — 투약 프로토타입 (PDA용)

Figma 디자인을 그대로 옮긴 클릭형 프로토타입입니다. 웹(HTML/CSS/JS)으로 만들고 Capacitor로 감싸 안드로이드 APK로 설치합니다.

- 디자인 기준: Figma `-neoPOCS-` 파일의 **SSol** 페이지 (2026-11-11부터). 1단계 **환자허브·AI 커맨드바·투약하기**, 2단계 **채혈하기·수혈하기·활력징후**, 3단계 **사용자설정·퀵메뉴·로그아웃·햄버거메뉴·주사실 설정·음성간호메모 메인·검토 화면**까지 반영했습니다.
- 이전 버전(v0.1~0.3)은 `Untitled` 파일의 Page 3(24개 화면) 기준입니다.

## 1. PDA에 설치하기 (MF52e)

1. PC와 PDA를 USB로 연결하고, APK 파일을 PDA의 `Download` 폴더에 복사합니다.
2. PDA에서 **파일(Files) 앱 → Download → neoPOCS-prototype-v0.3.0.apk**를 누릅니다.
3. "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용**을 켠 뒤 설치합니다.
4. 홈 화면의 **neo POCS** 아이콘으로 실행합니다.

> 예전에 디버그 서명 APK를 설치했거나 2026-11-11 이전에 Android Studio의 Run으로 실행했다면 서명이 달라 덮어쓰기가 안 됩니다. 기존 앱을 먼저 삭제한 뒤 설치하세요. 지금은 Android Studio의 Run(디버그 빌드)도 릴리스 키로 서명하므로, Run으로 깐 앱과 APK가 서로 덮어 설치됩니다.
> 이후 업데이트 APK도 같은 키로 서명해야 덮어쓰기 설치가 되므로 `android/keystore/`와 `android/keystore.properties`를 꼭 백업해 두세요.

USB 디버깅을 켰다면 PC에서 한 번에 설치하고 실행까지 할 수 있습니다. 어느 폴더에서 실행해도 되고, PowerShell·Git Bash 모두 같은 명령입니다.

```powershell
powershell -ExecutionPolicy Bypass -File C:/Users/toddk/xCLMA/neo-pocs-prototype/scripts/install-apk.ps1
```

- `release` 폴더의 가장 높은 버전 APK를 설치하고 PDA에서 앱을 바로 띄웁니다.
- PDA가 연결되지 않았거나 USB 디버깅 허용이 안 됐으면 무엇을 해야 하는지 안내합니다.
  (개발자 옵션 켜기: PDA **설정 → 휴대전화 정보 → 빌드 번호 7번 누르기** → **설정 → 시스템 → 개발자 옵션 → USB 디버깅** 켜기)
- 서명이 다른 예전 앱이 깔려 있어 덮어쓰기가 안 되면 뒤에 `-Reinstall`을 붙입니다(기존 앱 삭제 후 설치).

## 2. 시연 순서

로그인할 때마다 예시 데이터가 처음 상태로 돌아갑니다.

**야간모드**: 사용자설정의 **야간모드 스위치**를 켜면 **어두운 화면**으로 바뀌고(허브에 '🌙 야간모드' 표시), **알림·조작은 소리 대신 진동**으로 알립니다. 주간에는 짧은 효과음이 납니다: 스캔 '삑', 불일치·인식 불가 '삑삑', 안내 팝업·모드 전환 알림음, 수혈 15분 체크 알람, 수행 완료 멜로디, 길게 누르기 '틱'(소리는 화면을 한 번 누른 뒤부터 납니다). 야간에는 같은 상황에 진동 패턴이 오고, 진동이 없는 기기(PC·아이폰)에서는 화면 위에 잠깐 **'진동'** 표시가 뜹니다(시연용). 시간에 따른 자동 전환은 없습니다(요청으로 시간 설정 삭제). 로그아웃하면 꺼집니다.

**화면 공통**: **환자 이름 · 등록번호는 상단이 아니라 환자정보 박스 맨 위 줄**에 있습니다(허브 상단은 의료진 정보라 헷갈리지 않게). 업무 화면 상단에는 **업무명**(투약하기 · 채혈하기 · 수혈하기 · 활력징후 · 음성간호메모 · 환자 상세)이 나오고, 환자정보 박스가 없는 화면(수혈 시작 · 15분 체크 · 사진 측정값 확인 · 음성간호메모 · 완료 화면 · 환자 상세)에는 본문 맨 위에 **한 줄 환자 정보**(이름 · 등록번호 · 병상 · 상세정보)가 있습니다.

1. **로그인**: '아이디로 로그인' → 사번·비밀번호를 아무 값이나 입력 → 로그인 (빈칸이면 디자인의 오류 문구 표시). '생체인식으로 로그인' 화면은 로그인 버튼으로 통과합니다. 사원증 바코드/RFID를 스캔해도 바로 로그인됩니다.
2. **홈 허브**: 로그인하면 **환자허브**(긴급 처리 업무 3건 + 퀵메뉴 4개)가 열립니다. 좌우로 스와이프하면 왼쪽 **MY환자**, 오른쪽 **메뉴(24종)** 이고, 아래 점 3개가 현재 위치를 보여 줍니다. MY환자는 **이름 · 위치 · 업무** 정렬. 투약·채혈·수혈·활력징후 외의 메뉴는 안내 메시지만 표시합니다.
   - **긴급 처리 업무 카드**의 아이콘 아래에 업무명(**투약 · 채혈 · 수혈 · V/S**)이 표시됩니다. 카드를 누르면 그 환자의 해당 업무 화면이 **환자정보 비활성 · 업무 내용 흐린 상태**로 바로 열립니다(김철수 → 투약, 정민호 → 수혈, 안소율 → 활력징후). 아래 **'환자허브에서 업무 시작'** 참고. 업무를 마치면 카드가 사라지고 건수가 줄어듭니다.
   - **MY환자**에서 환자를 누르면 **업무 선택 시트**가 열립니다: 투약하기(대기 N건) · 채혈하기(대기 N관) · 수혈하기(대기 N건) · 활력징후(17:00 예정) 와 **환자상세 보기**. 오더가 없거나 이미 끝난 업무는 흐리게 표시되고 누를 수 없습니다. 업무를 마치면 환자 줄의 칩이 마지막 처리 업무(투약완료·채혈완료·수혈시작·VS완료)로 바뀝니다.
   - 어느 쪽에서 시작해도 **환자 팔찌 스캔은 그대로** 거칩니다. 이때 '스캔하기'는 고른 환자의 팔찌를 읽습니다(메뉴·퀵메뉴에서 바로 시작하면 김철수).
   - **AI 커맨드바**(맨 아래 입력창): **+** 버튼 3개(음성메모 · 사진 · 스캔)는 모두 환자 없이 바로 시작합니다.
     - **음성메모**: 바로 녹음 화면(제목 '음성메모', 환자 쪽 화자는 '환자') → ✓ → **'환자 팔찌 스캔'** 팝업 → 스캔한 환자로 검토·저장 → 완료 화면의 **음성간호메모 목록**으로 바로 이동할 수 있습니다.
     - **사진** (2026-11-23: 사진 촬영 · 사진첨부를 하나로): 바텀시트 → **사진 촬영**(환자 · 장비 · 기타 중 고르면 그 모드로 카메라가 열림. PDA에서는 기기 후면 카메라, 브라우저에서는 시연 화면) 또는 **갤러리에서 선택** → 촬영·선택 → **'환자 팔찌 스캔'** → 용도별 기록(8번).
     - **스캔**: 스캔 준비 화면. 환자 팔찌 → 그 환자의 **업무 선택 시트**(고른 업무는 팔찌가 확인된 상태로 열림), 처방 → 투약하기, 혈액 → 수혈하기(처방 우선), 채혈관 → 채혈하기(환자 먼저 안내).
     - '환자 팔찌 스캔' 팝업의 **스캔하기** = 김철수 팔찌, **길게 누르면** 6명 중 선택. PDA 스캐너로 팔찌를 읽어도 되고, 처방·혈액 바코드는 '환자 팔찌 바코드를 스캔해 주세요'로 안내합니다.
   - 글자를 입력하면 오른쪽 버튼이 ✓로 바뀌고, 환자 이름·등록번호('서동건' → 환자상세, '정민호 수혈' → 정민호 수혈 화면), '투약', '채혈', '내 환자', '메뉴', '음성메모'(녹음), '메모 목록', '모니터', '사진첨부', '스캔', '설정', '주사실', '로그아웃' 같은 말을 알아듣고 해당 화면으로 이동합니다. **음성 버튼**을 누르면 듣는 모습 뒤에 '김철수 환자 투약하기'가 입력되고, ✓를 누르면 실행됩니다 (시연용).
   - 맨 위 **사용자명(이수진(책임간호사))** → 사용자설정, **☰** → 햄버거메뉴.
3. **바코드 스캔**: '스캔하기' = 환자 팔찌 스캔. **길게 누르면 스캔 시뮬레이션**(6명의 환자 팔찌, 처방 먼저 스캔, 인식 실패)을 고를 수 있습니다. 인식 실패·불일치는 화면 위 **팝업**으로 안내합니다.
   - 다른 환자의 팔찌를 스캔하면 안내 없이 그 환자로 바뀝니다(기획: 영역 덮어쓰기). 처방을 먼저 스캔하면 처방에 적힌 환자로 맞춰지고, 이어서 다른 환자의 팔찌를 스캔하거나 환자 스캔 뒤 다른 환자의 처방·채혈관·혈액을 스캔하면 **불일치** 팝업이 뜹니다.
   - 그 업무의 오더가 없는 환자(예: 강태우 수혈)는 **'수행할 오더 없음'**, 오늘 업무를 이미 마친 환자는 **'채혈 완료'처럼 완료 안내** 팝업이 뜹니다.
3-1. **환자허브에서 업무 시작 (2026-11-23 요청: 투약 · 채혈 · 수혈 · VS 통일)**: **환자 선택 → 환자정보 확인(비활성) → 환자 팔찌 스캔(환자정보 활성) → 업무 수행**.
   - 긴급 카드 · MY환자 업무 선택 시트 · AI 커맨드바에 환자 이름("정민호 수혈")으로 시작하면 바코드 스캔 화면 없이 **그 환자의 업무 화면**이 열립니다. 환자정보 박스는 **흐리게 · 점선 · '환자 미확인'** 이고, 업무 내용(투약 목록 · 채혈관 · 혈액백 · VS 입력칸)도 흐리게 보이며 조작할 수 없습니다. 안내 '환자 팔찌를 스캔하면 환자정보가 활성화됩니다. 이어서 …'와 **환자 팔찌 스캔** 버튼(PDA 스캔 버튼으로도 됨, 길게 누르면 시뮬레이션).
   - 팔찌를 스캔하면 환자정보 박스가 **'✓ 환자 확인'**(파란 테두리)으로 활성화되고 업무를 진행합니다: 투약 → 투약 바코드 스캔(유지), 채혈 → 채혈관 바코드, 수혈 → 혈액백 바코드 2개, 활력징후 → 값 입력 · 저장.
   - 그 업무 오더가 없는 환자(AI 커맨드바 "강태우 수혈")는 바로 '수행할 오더 없음' 팝업. 질문해서 정한 것: 투약 바코드 단계 유지 · 스캔 전 업무 내용은 흐리게 미리 보기 · 환자를 고르지 않고 시작(메뉴 · 퀵메뉴 · AI 커맨드바 '채혈')하면 지금처럼 바코드 스캔 화면 먼저(스캔하면 바로 활성).
3-2. **업무 완료 후 돌아가는 화면 (2026-11-23 요청)**: 수행 완료 화면에서 **확인**을 누르면
   - **환자허브에서 환자를 골라 시작한 업무**(긴급 카드 · MY환자 업무 선택 시트 · AI 커맨드바 "정민호 수혈") → **환자허브**(시작했던 페이지: 긴급 처리 업무 또는 MY환자).
   - **업무 메뉴로 시작한 업무**(메뉴 페이지 · 퀵메뉴 · 햄버거메뉴 · AI 커맨드바 '채혈' · + → 스캔) → **그 업무의 바코드 스캔 화면**(다음 환자를 바로 스캔).
   - 투약 · 채혈 · 수혈(수혈 시작) · 활력징후 모두 같습니다.
4. **투약 목록**: **환자 팔찌 스캔 → 환자정보 확인**(환자정보 박스에 '✓ 환자 확인') · 투약 목록은 아직 흐린 상태로 **'투약 바코드 스캔'** 안내 카드와 버튼(길게 누르면 시뮬레이션: 이 환자 처방 · 다른 환자 처방 · 인식 실패)이 나옵니다 → **투약 바코드 스캔 → 투약 목록 활성화**. 고위험약물이 있으면 이때 1차 인증이 바로 열립니다. 다른 환자의 처방은 불일치 팝업입니다.
   - **환자를 고르고 들어오면**(긴급 카드 · MY환자 업무 선택 · AI 커맨드바 "김철수 투약") 바코드 스캔 화면 없이 **그 환자의 투약 목록이 먼저** 보입니다. 환자정보 박스는 비활성('환자 미확인'), 목록은 흐리게 잠겨 있고(시간·상태 변경·삭제 불가) '환자 팔찌를 스캔하면 환자정보가 활성화됩니다. 이어서 투약 바코드를…' 안내와 **환자 팔찌 스캔** 버튼이 있습니다(길게 누르면 시뮬레이션). 팔찌 다음은 위와 같이 투약 바코드 스캔입니다. 다른 환자의 팔찌를 스캔하면 **'환자 불일치'**(다시 스캔 / 그 환자로 변경), 다른 환자의 처방은 불일치 팝업입니다. 메뉴·퀵메뉴처럼 환자 없이 시작하면 바코드 스캔 화면이 먼저 나옵니다.
   - 처방을 먼저 스캔하면(바코드 스캔 화면) 환자 카드에 **'환자 스캔 — 환자 스캔 작업이 이행되지않았습니다.'** 가 표시되고 '환자정보 스캔하기'로 이어집니다.
   - `⏰ 17:00` 알약을 누르면 **투약 시간 변경** 시트, `Y` 태그를 누르면 **투약 수행 변경** 시트 (투약 외 선택은 붉게 표시). PRN 처방은 '실시간'으로 표시되고 시간·상태를 바꿀 수 없습니다.
   - 주의사항의 **파란 + 아이콘**(PRN 처방이 있을 때)을 누르면 PRN 처방 안내 팝업, 환자 정보 카드를 누르면 **환자 상세**로 이동합니다.
   - **약 삭제 (이번 투약에서 제외)**: 환자·처방 스캔 후 목록의 약 카드를 **왼쪽으로 밀거나 길게 누르면** 오른쪽에 **삭제 · 취소** 버튼이 나옵니다. 묶음처방은 약마다 따로 밀 수 있고, 이번 회차 투약이 없는 카드(완료·PRN)는 밀리지 않습니다.
     - **삭제** → 사유 선택(R-환자 거부 · N-금식 · NO-환자 부재 · H-처방 보류 · NO-기타) → 카드가 목록 아래 **'이번 투약에서 제외'** 로 흐리게 내려가고 사유와 **되돌리기**가 표시됩니다. 총 건수도 줄어듭니다.
     - 처방(의사 오더)은 지우지 않습니다. **투약수행**을 누르면 제외한 약은 투약되지 않고 그 시각에 사유 코드(R·N·H·NO)로 기록됩니다. 모든 약을 제외하면 '미투약 사유로 기록할까요?' 팝업이 뜹니다.
     - 고위험약물을 제외하면 1차·2차 인증 없이 투약할 수 있고, 되돌리면 인증이 다시 필요합니다. 화면을 나가면(뒤로가기·다른 환자) 제외는 취소됩니다.
5. **채혈하기** (퀵메뉴·메뉴·햄버거메뉴, 환자허브는 3-1처럼 비활성 화면부터): 순서가 정해져 있습니다.
   - **환자 바코드 스캔** → 채혈 목록(LR-D, Glu, Lipid · CBC, PT/aPTT, 검체번호·검체상세)이 열리고 각 채혈관이 '스캔 대기'로 표시됩니다. 채혈관을 먼저 스캔하면 '환자 스캔 필요' 팝업이 뜹니다.
   - **채혈관 바코드 스캔** → 해당 채혈관이 '✓ 확인'으로 바뀝니다. 채혈 오더가 2개 이상이면 버튼이 **'다른 채혈관 바코드 스캔'** 으로 바뀌고, 남은 채혈관을 모두 스캔할 때까지 이어집니다(같은 채혈관을 다시 스캔하면 '이미 확인된 채혈관', 다른 환자의 채혈관은 '환자/채혈관 불일치').
   - 모두 확인되면 **채혈 확인** → **채혈 완료** → 확인을 누르면 3-2처럼 환자허브 또는 채혈하기 바코드 스캔 화면으로 돌아갑니다.
   - 버튼을 길게 누르면 스캔 시뮬레이션(채혈관 선택·불일치·인식 실패)을 고를 수 있습니다.
   - 채혈·수혈 목록에는 **플랜 / 실시간** 선택이 없습니다(요청으로 제거, 투약·활력징후에만 있음).
6. **수혈하기** (긴급 카드·MY환자는 3-1처럼 비활성 화면부터, 메뉴는 바코드 스캔부터): **환자 팔찌 스캔 → 수혈하기 목록이 바로** 활성화됩니다(처방 스캔 단계 없음, 출고된 수혈 오더 전체 표시).
   - **혈액백 확인 = 바코드 2개**: 혈액백의 **혈액번호**와 **혈액제제** 바코드를 순서 상관없이 둘 다 스캔하면 그 혈액번호가 **확인**으로 바뀝니다. 하나만 스캔하면 안내 줄이 남은 바코드를 알려 주고(혈액번호만 찍으면 그 번호에 '제제 스캔' 표시), 다른 혈액백·다른 제제와 짝이 맞지 않으면 **'혈액번호/혈액제제 불일치'** 팝업이 뜹니다. 이미 확인·수혈한 혈액백, 다른 환자의 혈액도 안내합니다.
   - **혈액팩마다 카드 (2026-11-23)**: 혈액팩(혈액번호) 하나에 카드 하나 — 제제명 · 고위험 표시 · **'1/2 단위'** · 혈액번호 · 혈액형 · 용량 · 발행처/시간, 아래 줄에 상태: **대기 · 제제 스캔 · ✓ 확인 · 수혈 시작(시작 시각 · 15분 체크 예정/필요/이상 없음) · 중단**. 15분 체크가 필요한 카드에는 **체크하기** 버튼이 있습니다. 목록 머리의 배지는 '혈액팩 n개'.
   - '혈액 바코드 스캔' 버튼은 다음에 필요한 바코드(혈액번호 → 혈액제제)를 읽고, 길게 누르면 시뮬레이션(같은 혈액백 · 다른 제제 · 다른 환자 혈액 · 인식 실패)을 고릅니다. 확인된 혈액백이 생기면 **혈액 스캔 · 수행하기** 두 버튼이 됩니다. 남은 혈액팩이 없으면 **확인**.
   - **일부만 스캔해도 됩니다**: 확인된 혈액백만 수혈하고, 나머지는 '대기'로 남아 다음 혈액백을 걸 때 스캔합니다(7개가 한 번에 오지 않는 상황).
   - **수행하기** → **수혈하기 1차 인증**(4개 항목, 혈액번호·'3/8 단위' 표시, 1차 이수진) → **고위험수행 이중 확인** 팝업에서 2차 담당자 RFID(또는 확인) → **수혈하기 2차 인증**(1차는 파란색으로 채워 표시, 2차 김수아) → **고위험수행 이중 확인 완료** → 확인 → **수혈 시작 기록**(아래 6-1).
   - **이중 인증은 항목마다 처음 한 번만**: 같은 항목(예: Red Cell 7개)의 두 번째 혈액백부터는 **혈액번호 스캔만** 하고 이중 인증 없이 수행하기 → 바로 수혈 시작 기록. 다른 항목(예: White Cell)의 첫 혈액백은 바코드 2개와 이중 인증을 거칩니다.
   - 혈액 바코드를 먼저 스캔하면 목록에 '환자 스캔' 경고가 뜨고 팔찌 스캔으로 이어지며, 목록이 열린 뒤 다른 환자의 혈액을 스캔하면 불일치 팝업, 이미 시작한 혈액팩은 '이미 수혈을 시작한 혈액입니다.'
   6-1. **수혈 시작 · 15분 체크** (디자인에 없는 화면, 2026-11-23 요청으로 **수혈 진행 화면(혈액팩 애니메이션 · 예상 종료 · 경과 · 긴급 종료) 삭제, 종료 시각 체크 없음**):
   - 이중 인증 완료(또는 같은 항목의 다음 혈액백 수행하기) → **수혈 시작 시각만 기록** → **'수혈 시작' 완료 화면**: 혈액팩 카드(제제 · n/m 단위 · 혈액번호 · 혈액형 · 용량)와 **수혈 시작 17:30 · 15분 체크 17:45**, 남은 혈액팩 수 → 확인 → 3-2처럼 환자허브 또는 수혈하기 바코드 스캔 화면.
   - **15분 알람**: 수혈 시작 15분 뒤 **어느 화면에서든** 알람(주간 알람음 · 야간 진동) + 팝업 **'수혈 15분 체크'**(환자 · 제제 · 혈액번호 · 시작/체크 시각) → **나중에 / 체크하기**. **시연에서는 15초 뒤**에 울리고, 화면의 시각은 실제 15분 기준으로 보여 줍니다. 팝업·시트가 열려 있으면 닫힌 뒤에 울립니다.
   - **나중에** → 환자허브 **긴급 처리 업무 맨 위에 '15분 체크 필요' 카드**(주황 테두리)가 남고, 그 환자의 혈액팩 카드에도 **체크하기**가 보입니다. 둘 중 하나를 누르면 체크 화면으로 갑니다.
   - **체크하기** → **15분 중간 체크**(팔찌 스캔 없이 바로 기록): 혈액팩 카드(수혈 시작 · 15분 체크 시각) + 활력징후 6항목(빈 칸, '이전' 값, **음성 입력** · −/+ · 직접 입력, 6항목 모두 필요) + **이상반응 체크리스트**(발열·오한·두드러기/가려움·호흡곤란·흉통/요통·저혈압/빈맥). 이상이 없으면 **'이상 없음 · 수혈 계속'** → 기록하고 **체크 전 화면으로** 돌아갑니다(다른 환자 업무 중이었다면 그 환자로 되돌아가고, 그 업무는 팔찌를 다시 스캔). 하나라도 고르면 **'이상반응 · 수혈 중단'** → 확인 팝업 → **수혈 중단** 화면(시작 · 중단 시각, 사유) → 확인 → 체크 전 화면. 체크한 활력징후는 환자상세 임상관찰기록에 반영됩니다. 닫기(✕)는 체크를 나중으로 미룹니다.
   - 모든 혈액팩을 시작(또는 중단)하면 긴급 카드가 사라지고 MY환자 칩이 **'수혈시작'**(중단 시 '수혈중단')으로 바뀝니다. 일부만 시작했으면 업무 선택 시트에 '진행 1/2'.
7. **활력징후** (퀵메뉴·메뉴, 초록 테마): 환자 스캔만 하면 측정 화면이 열립니다(플랜/실시간 없음). 환자허브에서 고르면 측정 화면이 비활성(입력칸 흐리게 · 잠김)으로 먼저 열리고 팔찌 스캔으로 활성화됩니다(같은 팔찌를 다시 스캔하면 '이미 확인된 환자', 입력값 유지).
   - **칸은 비어서 시작**하고, 칸마다 **'이전 118 · 15:30'**(직전 기록, 주의·경고 값은 색)이 보입니다(이전 값을 그대로 저장해 새 측정값처럼 남는 일을 막기 위해).
   - **빈 칸이 있어도 저장 (2026-11-23)**: 1개 이상 입력하면 저장되고, 입력한 항목만 기록됩니다. 완료 화면에 '활력징후 5개 항목 … 미입력 : BT'로 보이고, 환자 상세 임상관찰기록에는 그 항목이 '미측정'(상세보기 표는 '-'), 다음 측정의 '이전' 값은 그 항목을 잰 마지막 기록에서 가져옵니다. 하나도 입력하지 않으면 '측정값을 1개 이상 입력해 주세요.'
   - 입력: **음성 입력**(아래) · **사진 입력**(카드 위 📷 사진 입력 → '활력징후 사진 입력' 카메라: 환자 모니터만 찾고 팔찌 스캔 없음 → 촬영하면 인식한 값(SBP 125 · DBP 81 · PR 66 · RR 17 · SpO2 98, 모니터에 없는 BT는 빈 칸)이 **입력 칸에 바로 채워지고 강조**, 신뢰도가 낮은 RR은 '확인해 주세요' 안내. 흐린 사진 · 모니터가 아닌 사진은 다시 촬영 / 직접 입력) · **빈 칸을 누르면 직전 값이 채워지고 선택**되어 바로 숫자를 치면 바뀜(그대로 두면 그 값이 입력됨, 사진 측정값 확인 · 수혈 15분 체크도 같음) · **−/+**(BT는 0.1 단위, 빈 칸에서 누르면 이전 값부터). 정상/주의/경고(빈 칸은 '미입력')가 바로 바뀝니다. **초기화**는 칸을 비웁니다.
   - **측정 시간**: 화면을 열 때 현재 시각으로 채워지고, 아래 `⏰ 날짜 시:분`을 누르면 **시 · 분 조절 시트**(▲▼ 1분 단위, 길게 누르면 빠르게, '지금')에서 바꿉니다. 저장하면 그 시각으로 임상관찰기록에 남습니다.

## 3. PDA 스캐너 연동

- 별도 SDK 없이 **키보드 입력(Keyboard wedge)** 방식으로 동작합니다. Point Mobile `설정 → ScanSettings → 결과 전달 방식`을 **키보드 이벤트(Keyboard event)**, 종료 문자 **Enter**로 두면 됩니다.
- 인텐트 방식도 받을 수 있습니다: action `com.softbowl.neopocs.SCAN`, extra `data`(문자열).
- 바코드 규칙: 등록번호 또는 `P`+등록번호 → 그 환자 / `D?001`… → 투약 처방, `B?001`…(또는 검체번호) → 채혈관, `T?001`…(또는 혈액번호) → 수혈 혈액 제제 (`?` = 환자 순번 1~6, 위 표 참고) / 다른 환자의 처방·채혈관·혈액 → 불일치 / 표에 없는 `D…`, 끝이 `9999`인 코드 → 불일치 / 그 외 아무 바코드 → 지금 환자의 다음 단계(환자 → 처방)로 진행. 채혈하기는 환자 바코드를 먼저 스캔해야 합니다. 활력징후·사진 촬영·사진첨부에서는 등록되지 않은 바코드도 지금 환자로 인식합니다.

## 6. 개발·빌드

```bash
npm install
npm run dev
```

- 브라우저에서 `http://localhost:5173` → Figma 프레임과 같은 412×892 크기로 보입니다(휴대폰 브라우저는 자동으로 꽉 채운 배치). `http://localhost:5173/?device` 는 PDA처럼 화면 폭에 맞춘 배치, `?pc` 는 휴대폰에서도 액자입니다.
- APK 다시 만들기: `powershell -ExecutionPolicy Bypass -File scripts\build-apk.ps1` (JDK 21: `%USERPROFILE%\.jdks`, Android SDK: `%LOCALAPPDATA%\Android\Sdk`)
- 디자인 비교: `node scripts/shoot-ssol.mjs <폴더> [h,m | b,t,v | p3-]` 로 SSol 화면 50개(1단계 h·m, 2단계 b·t·v, 3단계 p3-)를 캡처하고(3단계 파일은 앞의 `p3-`를 떼고 `design-p3`와 비교) `python scripts/compare.py ../figma-ssol/design-p1(또는 design-p2) <캡처폴더> <결과폴더>` 로 나란히 비교합니다. 디자인 렌더는 `C:\Users\toddk\xCLMA\figma-ssol\`에 저장돼 있어 Figma를 다시 호출하지 않아도 됩니다.
- 흐름 점검: `node scripts/flow-test.mjs` (로그인 → AI 커맨드바 → 투약·고위험 인증 → 음성간호메모 검토·다시 요약 → 채혈 → 수혈·고위험수행 인증 → 수혈 시작 · 15분 알람 · 체크 · 중단 → 활력징후 저장(빈 칸 · 사진 입력) → 환자상세 → 사용자설정·퀵 슬롯 → 주사실 → 음성간호메모 검토 → 로그아웃까지 자동 클릭)
- 새 디자인의 3D 아이콘(스캔·퀵메뉴·긴급업무·아바타·초록 스캔/완료)은 `python scripts/extract_ssol_icons.py ../figma-ssol src/assets/img/3d`, 활력징후 초록 배경은 `python scripts/make_green_bg.py ../figma-ssol/design-p2 src/assets/img/bg-green.png` 로 다시 만들 수 있습니다.
