# neo POCS V2 — 투약 프로토타입 (PDA용)

Figma 디자인을 그대로 옮긴 클릭형 프로토타입입니다. 웹(HTML/CSS/JS)으로 만들고 Capacitor로 감싸 안드로이드 APK로 설치합니다.

- 디자인 기준: Figma `-neoPOCS-` 파일의 **SSol** 페이지 (2026-11-11부터). 1단계 **환자허브·AI 커맨드바·투약하기**, 2단계 **채혈하기·수혈하기·활력징후**, 3단계 **사용자설정·퀵메뉴·로그아웃·햄버거메뉴·주사실 설정·음성간호메모 메인·검토 화면**까지 반영했습니다.
- 이전 버전(v0.1~0.3)은 `Untitled` 파일의 Page 3(24개 화면) 기준입니다.

| 항목 | 내용 |
|---|---|
| 설치 파일 | `release/neoPOCS-prototype-v0.3.0.apk` (약 6.6MB, 버전 0.3.0) |
| 패키지명 | `com.softbowl.neopocs.prototype` · 앱 이름 `neo POCS` |
| 지원 OS | Android 7.0 이상 (대상 기기: Point Mobile MF52e, Android 15) |
| 서명 | 릴리스 서명 (전용 키 `android/keystore/`, 비밀번호는 `android/keystore.properties`) |

## 1. PDA에 설치하기 (MF52e)

1. PC와 PDA를 USB로 연결하고, APK 파일을 PDA의 `Download` 폴더에 복사합니다.
2. PDA에서 **파일(Files) 앱 → Download → neoPOCS-prototype-v0.3.0.apk**를 누릅니다.
3. "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용**을 켠 뒤 설치합니다.
4. 홈 화면의 **neo POCS** 아이콘으로 실행합니다.

> 예전에 디버그 서명 APK를 설치했거나 2026-11-11 이전에 Android Studio의 Run으로 실행했다면 서명이 달라 덮어쓰기가 안 됩니다. 기존 앱을 먼저 삭제한 뒤 설치하세요. 지금은 Android Studio의 Run(디버그 빌드)도 릴리스 키로 서명하므로, Run으로 깐 앱과 APK가 서로 덮어 설치됩니다.
> 이후 업데이트 APK도 같은 키로 서명해야 덮어쓰기 설치가 되므로 `android/keystore/`와 `android/keystore.properties`를 꼭 백업해 두세요.

USB 디버깅을 켰다면 PC에서 한 번에 설치하고 실행까지 할 수 있습니다. 어느 폴더에서 실행해도 되고, PowerShell·Git Bash 모두 같은 명령입니다.

```powershell
powershell -ExecutionPolicy Bypass -File C:/Users/toddk/xCLMA/neo-pocs-prototype/scripts/install-apk.ps1
```

- `release` 폴더의 가장 높은 버전 APK를 설치하고 PDA에서 앱을 바로 띄웁니다.
- PDA가 연결되지 않았거나 USB 디버깅 허용이 안 됐으면 무엇을 해야 하는지 안내합니다.
  (개발자 옵션 켜기: PDA **설정 → 휴대전화 정보 → 빌드 번호 7번 누르기** → **설정 → 시스템 → 개발자 옵션 → USB 디버깅** 켜기)
- 서명이 다른 예전 앱이 깔려 있어 덮어쓰기가 안 되면 뒤에 `-Reinstall`을 붙입니다(기존 앱 삭제 후 설치).

## 2. 시연 순서

로그인할 때마다 예시 데이터가 처음 상태로 돌아갑니다.

1. **로그인**: '아이디로 로그인' → 사번·비밀번호를 아무 값이나 입력 → 로그인 (빈칸이면 디자인의 오류 문구 표시). '생체인식으로 로그인' 화면은 로그인 버튼으로 통과합니다. 사원증 바코드/RFID를 스캔해도 바로 로그인됩니다.
2. **홈 허브**: 로그인하면 **환자허브**(긴급 처리 업무 3건 + 퀵메뉴 4개)가 열립니다. 좌우로 스와이프하면 왼쪽 **MY환자**, 오른쪽 **메뉴(24종)** 이고, 아래 점 3개가 현재 위치를 보여 줍니다. MY환자는 **이름 · 위치 · 업무** 정렬. 투약·채혈·수혈·활력징후 외의 메뉴는 안내 메시지만 표시합니다.
   - **긴급 처리 업무 카드**를 누르면 그 환자의 해당 업무 바코드 스캔 화면으로 갑니다(김철수 → 투약, 정민호 → 수혈, 안소율 → 활력징후). 업무를 마치면 카드가 사라지고 건수가 줄어듭니다.
   - **MY환자**에서 환자를 누르면 **업무 선택 시트**가 열립니다: 투약하기(대기 N건) · 채혈하기(대기 N관) · 수혈하기(대기 N건) · 활력징후(17:00 예정) 와 **환자상세 보기**. 오더가 없거나 이미 끝난 업무는 흐리게 표시되고 누를 수 없습니다. 업무를 마치면 환자 줄의 칩이 마지막 처리 업무(투약완료·채혈완료·수혈완료·VS완료)로 바뀝니다.
   - 어느 쪽에서 시작해도 **환자 팔찌 스캔은 그대로** 거칩니다. 이때 '스캔하기'는 고른 환자의 팔찌를 읽습니다(메뉴·퀵메뉴에서 바로 시작하면 김철수).
   - **AI 커맨드바**(맨 아래 입력창): **+** 버튼 4개는 모두 환자 없이 바로 시작합니다.
     - **음성메모**: 바로 녹음 화면(제목 '음성메모', 환자 쪽 화자는 '환자') → ✓ → **'환자 팔찌 스캔'** 팝업 → 스캔한 환자로 검토·저장 → 완료 화면의 **음성간호메모 목록**으로 바로 이동할 수 있습니다.
     - **사진 촬영**: 카메라 화면이 바로 열립니다(PDA에서는 기기 후면 카메라, 브라우저에서는 시연용 병상 화면). 촬영 → **'환자 팔찌 스캔'** → AI 분석 → 측정값 확인.
     - **스캔**: 스캔 준비 화면. 환자 팔찌 → 그 환자의 **업무 선택 시트**(고른 업무는 팔찌가 확인된 상태로 열림), 처방 → 투약하기, 혈액 → 수혈하기(처방 우선), 채혈관 → 채혈하기(환자 먼저 안내).
     - **사진첨부**: 기기 갤러리가 바로 열립니다(PDA는 안드로이드 사진 선택, 브라우저는 시연 앨범). 사진 선택 → **'환자 팔찌 스캔'** → AI 분석.
     - '환자 팔찌 스캔' 팝업의 **스캔하기** = 김철수 팔찌, **길게 누르면** 6명 중 선택. PDA 스캐너로 팔찌를 읽어도 되고, 처방·혈액 바코드는 '환자 팔찌 바코드를 스캔해 주세요'로 안내합니다.
   - 글자를 입력하면 오른쪽 버튼이 ✓로 바뀌고, 환자 이름·등록번호('서동건' → 환자상세, '정민호 수혈' → 정민호 수혈 스캔), '투약', '채혈', '내 환자', '메뉴', '음성메모'(녹음), '메모 목록', '모니터', '사진첨부', '스캔', '설정', '주사실', '로그아웃' 같은 말을 알아듣고 해당 화면으로 이동합니다. **음성 버튼**을 누르면 듣는 모습 뒤에 '김철수 환자 투약하기'가 입력되고, ✓를 누르면 실행됩니다 (시연용).
   - 맨 위 **사용자명(이수진(책임간호사))** → 사용자설정, **☰** → 햄버거메뉴.
3. **바코드 스캔**: '스캔하기' = 환자 팔찌 스캔. **길게 누르면 스캔 시뮬레이션**(6명의 환자 팔찌, 처방 먼저 스캔, 인식 실패)을 고를 수 있습니다. 인식 실패·불일치는 화면 위 **팝업**으로 안내합니다.
   - 다른 환자의 팔찌를 스캔하면 안내 없이 그 환자로 바뀝니다(기획: 영역 덮어쓰기). 처방을 먼저 스캔하면 처방에 적힌 환자로 맞춰지고, 이어서 다른 환자의 팔찌를 스캔하거나 환자 스캔 뒤 다른 환자의 처방·채혈관·혈액을 스캔하면 **불일치** 팝업이 뜹니다.
   - 그 업무의 오더가 없는 환자(예: 강태우 수혈)는 **'수행할 오더 없음'**, 오늘 업무를 이미 마친 환자는 **'채혈 완료'처럼 완료 안내** 팝업이 뜹니다.
4. **투약 목록**: 환자 스캔 후 '처방정보 스캔하기'(길게 누르면 불일치·인식 실패 선택). 처방을 먼저 스캔하면 환자 카드에 **'환자 스캔 — 환자 스캔 작업이 이행되지않았습니다.'** 가 표시되고 '환자정보 스캔하기'로 이어집니다.
   - `⏰ 17:00` 알약을 누르면 **투약 시간 변경** 시트, `Y` 태그를 누르면 **투약 수행 변경** 시트 (투약 외 선택은 붉게 표시). PRN 처방은 '실시간'으로 표시되고 시간·상태를 바꿀 수 없습니다.
   - 주의사항의 **파란 + 아이콘**(PRN 처방이 있을 때)을 누르면 PRN 처방 안내 팝업, 환자 정보 카드를 누르면 **환자 상세**로 이동합니다.
5. **채혈하기** (퀵메뉴·메뉴·햄버거메뉴): 순서가 정해져 있습니다.
   - **환자 바코드 스캔** → 채혈 목록(LR-D, Glu, Lipid · CBC, PT/aPTT, 검체번호·검체상세)이 열리고 각 채혈관이 '스캔 대기'로 표시됩니다. 채혈관을 먼저 스캔하면 '환자 스캔 필요' 팝업이 뜹니다.
   - **채혈관 바코드 스캔** → 해당 채혈관이 '✓ 확인'으로 바뀝니다. 채혈 오더가 2개 이상이면 버튼이 **'다른 채혈관 바코드 스캔'** 으로 바뀌고, 남은 채혈관을 모두 스캔할 때까지 이어집니다(같은 채혈관을 다시 스캔하면 '이미 확인된 채혈관', 다른 환자의 채혈관은 '환자/채혈관 불일치').
   - 모두 확인되면 **채혈 확인** → **채혈 완료** → 확인을 누르면 채혈 업무가 끝나고 환자허브로 돌아갑니다.
   - 버튼을 길게 누르면 스캔 시뮬레이션(채혈관 선택·불일치·인식 실패)을 고를 수 있습니다.
6. **수혈하기** (긴급 카드·MY환자·메뉴): **환자 팔찌 스캔 → 수혈하기 목록이 바로** 열립니다(처방 스캔 단계 없음). 목록에서 **수행하기** → **수혈하기 1차 인증**(4개 항목, 1차 이수진) → **고위험수행 이중 확인** 팝업에서 2차 담당자 RFID(또는 확인) → **수혈하기 2차 인증**(1차는 파란색으로 채워 표시, 2차 김수아) → **고위험수행 이중 확인 완료** → 확인 → **수혈 진행 화면**(아래 6-1). 목록에서 `Y` 태그를 누르면 **수행 변경**(Y-수혈 시작 / E-종료). 혈액 제제를 먼저 스캔하면 목록에 '환자 스캔' 경고가 뜨고 팔찌 스캔으로 이어지며, 목록이 열린 뒤 다른 환자의 혈액을 스캔하면 불일치 팝업이 뜹니다.
   6-1. **수혈 진행** (디자인에 없는 화면):
   - 혈액팩(남은 양 %·ml, 눈금), 혈액번호·혈액형·용량, '1/2 단위' 표시. **수혈 시작**을 누르면 시작 시각이 기록되고, **예상 종료 시각**(Red Cell 300ml · 2시간), 경과 시간, **15분 중간 체크까지 남은 시간**이 흐르며 혈액팩의 혈액이 줄어들고 점적통에 방울이 떨어집니다.
   - **시연 속도**: 실시간 · ×60(기본) · ×600. 시각은 수혈 시작 순간의 실제 시각에서 시작해 배속으로 흐릅니다.
   - **15분 중간 체크**: 15분이 되면 진동·팝업 → **체크하기** → 활력징후 6항목(마지막 기록이 채워져 있음, −/+ 또는 직접 입력) + **이상반응 체크리스트**(발열·오한·두드러기/가려움·호흡곤란·흉통/요통·저혈압/빈맥). 이상이 없으면 **'이상 없음 · 수혈 계속'**, 하나라도 고르면 **'이상반응 · 긴급 종료'**. 체크한 활력징후는 환자상세 임상관찰기록에 반영됩니다. 시연 배속에서는 체크하는 동안 시계가 멈춥니다.
   - **긴급 종료**(수혈 중 언제든): 종료 사유 선택(이상반응 6종 · 정맥로 문제 · 환자 거부/요청 · 기타) → 그 시각까지의 투여량과 함께 기록 → **수혈 중단** 화면.
   - 혈액팩이 비면 **수혈 완료** → 종료 시각·투여량 기록. 다음 단위가 있으면 **혈액번호 스캔**(다른 환자 혈액은 불일치, 이미 수혈한 단위는 안내) → 다시 **수혈 시작**(15분 체크 반복). 모든 단위가 끝나면 **수혈 완료** 화면에 단위별 시작–종료·투여량·15분 체크·총 투여량이 남습니다.
   - 수혈이 시작된 뒤에는 뒤로가기·☰로 나갈 수 없고('수혈 진행 중' 안내), 완료 또는 긴급 종료로 마칩니다. 끝나면 긴급 카드가 사라지고 MY환자 칩이 '수혈완료'(중단 시 '수혈중단')로 바뀝니다.
7. **활력징후** (퀵메뉴·메뉴, 초록 테마): 환자 스캔만 하면 측정 화면이 열립니다. SBP·DBP·PR·RR·BT·SpO2를 **−/+**(BT는 0.1 단위)로 조절하거나 숫자를 눌러 직접 입력하면 정상/주의/경고가 바로 바뀝니다. **플랜**을 누르면 측정 시간(09/13/17/21시) 선택, **실시간**은 현재 시각, **초기화**는 마지막 기록으로 되돌립니다. **저장하기** → 수행 완료 → 환자 상세의 임상관찰기록에 반영.
8. **사진 촬영 → 활력징후 OCR** (AI 커맨드바 **+ → 사진 촬영**): 카메라가 바로 열리고(위쪽 칩 '환자 미확인 · 촬영 후 팔찌 스캔'), 촬영하면 **'환자 팔찌 스캔'** 팝업 → 스캔한 환자로 분석합니다. **PDA(APK)에서는 기기 후면 카메라 화면**이 나오고 촬영한 사진이 그대로 멈춰 분석·결과 화면 썸네일에 쓰입니다. 무엇을 찍든 분석 결과는 시연용 측정값이며, 카메라를 쓸 수 없으면 시연 화면으로 바뀝니다. 다시 촬영할 때는 팔찌를 다시 묻지 않습니다.
   - **사진첨부** (**+ → 사진첨부**): **PDA에서는 안드로이드 사진 선택(갤러리)** 이 바로 열리고, 고른 사진을 전체 화면에 보여 준 뒤 **'환자 팔찌 스캔'** → 같은 AI 분석. 브라우저에서는 **전체 화면 '사진 선택' 갤러리**(4열 격자, 오늘·어제·9월 15일, 26장 — 병실에서 찍은 사진·메모·화면 캡처)가 대신 열리고, 사진을 눌러 선택한 뒤 **첨부하기**를 누릅니다. 분석 결과는 사진 내용대로입니다: 모니터가 선명한 사진은 측정값 인식, 흔들리거나 빛이 반사된 사진은 '측정값을 읽을 수 없습니다', 모니터가 없는 사진(수액 거치대·베개·메모 등)은 '환자 모니터를 찾지 못했습니다'. PDA에서도 '갤러리에서 선택'을 **길게 누르면** 이 시연 갤러리를 열 수 있습니다. 모니터 사진은 인식 결과 화면으로, 흔들린 사진은 '측정값을 읽을 수 없습니다', 모니터가 없는 사진은 '환자 모니터를 찾지 못했습니다'와 함께 **직접 입력 · 다른 사진 선택**을 고를 수 있습니다. **AI 카메라 촬영** 화면 — 병상 모니터를 비추는 카메라(사각 영역 안만 밝고 주변은 어둡게).
   - 앱은 무엇이 찍힐지 미리 알 수 없으므로, 화면은 지금 보이는 것만 안내합니다: 모니터를 찾는 중(흰 사각 · '사각 영역 안에 맞춰 주세요') → 사각 영역에서 모니터를 찾아 포커스가 맞으면 **'환자 모니터 감지'** 뱃지와 함께 하단에 **'환자 모니터가 감지되었습니다'**(촬영 버튼을 눌러 주세요) → 촬영하면 안내 문구를 숨기고 '촬영한 이미지를 확인하고 있습니다 → 측정값을 찾고 있습니다 → 측정값 n개 인식'으로 진행.
   - 인식되면 값 확인·수정 → 최종 확인 → EMR 전송 → 환자 상세의 임상관찰기록에 반영. 시연용으로 호흡(awRR 11)을 17로 잘못 인식해 '확인 필요'로, 모니터에 체온이 없어 체온을 '미인식 · 직접 입력'으로 표시합니다.
   - 모니터가 감지되기 전에 찍거나 사진이 흐리면 '환자 모니터를 찾지 못했습니다' / '측정값을 읽을 수 없습니다'와 함께 **다시 촬영 · 직접 입력**을 고를 수 있습니다.
   - 화면의 촬영 버튼을 **길게 누르면 촬영 시뮬레이션**(정상 인식 · 모니터가 없는 사진 · 흐린 사진)을 고를 수 있습니다. 촬영·인식은 시뮬레이션입니다.
9. **음성간호메모 녹음·검토** (투약·채혈·수혈·활력징후·환자상세의 '음성간호메모 진행하기'): 대화가 한 줄씩 전사되는 모습 → 입력창에 메모 입력 시 전송 버튼 활성화(입력창의 **+** 는 AI 커맨드바와 같은 메뉴: 음성메모 · 사진 촬영 · 스캔 · 사진첨부, 누르면 '녹음 중인 메모는 저장되지 않습니다' 확인 후 이동) → ✓ → **검토 화면**: 한 카드 안에 'AI 음성간호메모 요약'과 '시간별 대화 스크립트'(접힘). 요약과 스크립트 문장은 눌러서 바로 고칠 수 있고, 스크립트를 고치면 **'대화내용 다시 요약하기'** 가 켜집니다(시연용으로 요약 문구는 그대로 두고 다시 요약한 것처럼 보여 줍니다) → 저장 → 완료. 저장한 메모는 음성간호메모 목록에 '확인완료'로 추가됩니다. (AI 커맨드바 **+ → 음성메모**는 환자 없이 녹음부터 하고, 끝나면 팔찌 스캔으로 환자를 정합니다 — 2번 참고.)
10. **고위험약물 이중확인**: 환자와 처방이 모두 스캔되면 고위험약물(대한 디-만니톨주사액, 마약)이 있어 **고위험약물 1차 인증**이 바로 열립니다. 1차 담당자는 로그인한 **이수진 간호사 N20240182**. 5개 항목 체크 → 확인 → **2차 인증 팝업**('사용자의 RFID 바코드를 스캔하세요')에서 2차 담당자 RFID를 스캔하거나 확인을 누르면 **김수아 간호사 N23240183** 으로 2차 인증 → 5개 항목 체크 → **고위험약물 이중점검 완료**(1차·2차 담당자와 시각) → 투약 목록으로 돌아옵니다. 인증 전에 닫으면 '투약수행' 버튼이 흐리게 표시되고, 누르면 인증 화면을 다시 엽니다.
11. **투약수행** → **수행 완료** → 확인을 누르면 투약하기 바코드 스캔 화면으로 돌아갑니다(투약 기록은 유지되어 다시 스캔하면 반영된 기록이 보입니다).
12. 투약·채혈·수혈·활력징후·환자상세 화면에서 **뒤로가기·☰**를 누르면 **'환자정보 초기화'** 팝업(취소/확인) → 확인 시 환자허브(☰는 햄버거메뉴)로 갑니다. PDA의 하드웨어 뒤로가기 키도 같은 동작을 합니다.
13. **사용자설정** (허브 맨 위 사용자명): 인사 카드 · 긴급처리업무/MY환자 수(누르면 해당 페이지) · **메뉴별 알림 설정**(6개 분류 접기/펼치기, 메뉴별 켜기/끄기, 투약·채혈·수혈·활력징후는 경과 알림 10/20/30분) · **퀵 메뉴 설정**(슬롯을 누르면 1단계 분류 → 2단계 메뉴 선택) · 고위험수행 2차인증 · 자동 로그아웃(10/20/30/60분) · 로그아웃.
   - 설정은 바로 허브에 반영됩니다: 수혈하기 알림을 끄면 정민호 카드가 빠지고 '긴급 처리 업무가 2건', 투약 경과를 20분으로 바꾸면 '투약 오더 20분 경과', 퀵 슬롯을 바꾸면 허브 퀵메뉴가 바뀝니다. (이미 끝낸 업무의 카드는 알림을 켜도 다시 나오지 않습니다.)
   - **로그아웃** → '로그아웃 안내' 팝업 → 로그인 화면. 설정·주사실도 처음 상태로 돌아갑니다(다시 로그인만 하면 설정은 유지).
14. **햄버거메뉴** (☰): 홈(환자 허브) · **주사실 설정**(8개 중 선택, 고르면 타일에 표시) · **음성간호메모**(확인대기 건수, 메모 목록으로 이동) · 전체 메뉴 24종(6개 분류) · 앱 버전. 투약·채혈·수혈·활력징후는 바로 시작되고, 나머지는 안내 메시지를 띄웁니다.
15. **음성간호메모 메인** (햄버거메뉴 타일 · 음성메모 저장 완료 화면 · AI 커맨드바 '메모 목록'): '확인대기 음성간호메모가 N건' + 메모가 있는 환자 목록(김철수·문가은·서동건·안소율) → 환자를 누르면 그 환자의 **수행별 / 병상 라운딩** 탭 메모 카드(요약, 대화 스크립트 펼치기). **'AI가 요약한 콘텐츠를 검토했습니다.'** 를 체크하면 '확인대기'가 '확인완료'로 바뀌고 메인의 건수도 줄어듭니다.

## 3. PDA 스캐너 연동

- 별도 SDK 없이 **키보드 입력(Keyboard wedge)** 방식으로 동작합니다. Point Mobile `설정 → ScanSettings → 결과 전달 방식`을 **키보드 이벤트(Keyboard event)**, 종료 문자 **Enter**로 두면 됩니다.
- 인텐트 방식도 받을 수 있습니다: action `com.softbowl.neopocs.SCAN`, extra `data`(문자열).
- 바코드 규칙: 등록번호 또는 `P`+등록번호 → 그 환자 / `D?001`… → 투약 처방, `B?001`…(또는 검체번호) → 채혈관, `T?001`…(또는 혈액번호) → 수혈 혈액 제제 (`?` = 환자 순번 1~6, 위 표 참고) / 다른 환자의 처방·채혈관·혈액 → 불일치 / 표에 없는 `D…`, 끝이 `9999`인 코드 → 불일치 / 그 외 아무 바코드 → 지금 환자의 다음 단계(환자 → 처방)로 진행. 채혈하기는 환자 바코드를 먼저 스캔해야 합니다. 활력징후·사진 촬영·사진첨부에서는 등록되지 않은 바코드도 지금 환자로 인식합니다.

## 6. 개발·빌드

```bash
npm install
npm run dev
```

- 브라우저에서 `http://localhost:5173` → Figma 프레임과 같은 412×892 크기로 보입니다. `http://localhost:5173/?device` 는 PDA처럼 화면 폭에 맞춘 배치입니다.
- APK 다시 만들기: `powershell -ExecutionPolicy Bypass -File scripts\build-apk.ps1` (JDK 21: `%USERPROFILE%\.jdks`, Android SDK: `%LOCALAPPDATA%\Android\Sdk`)
- 디자인 비교: `node scripts/shoot-ssol.mjs <폴더> [h,m | b,t,v | p3-]` 로 SSol 화면 50개(1단계 h·m, 2단계 b·t·v, 3단계 p3-)를 캡처하고(3단계 파일은 앞의 `p3-`를 떼고 `design-p3`와 비교) `python scripts/compare.py ../figma-ssol/design-p1(또는 design-p2) <캡처폴더> <결과폴더>` 로 나란히 비교합니다. 디자인 렌더는 `C:\Users\toddk\xCLMA\figma-ssol\`에 저장돼 있어 Figma를 다시 호출하지 않아도 됩니다.
- 흐름 점검: `node scripts/flow-test.mjs` (로그인 → AI 커맨드바 → 투약·고위험 인증 → 음성간호메모 검토·다시 요약 → 채혈 → 수혈·고위험수행 인증 → 활력징후 저장 → 환자상세 → 사용자설정·퀵 슬롯 → 주사실 → 음성간호메모 검토 → 로그아웃까지 자동 클릭)
- 새 디자인의 3D 아이콘(스캔·퀵메뉴·긴급업무·아바타·초록 스캔/완료)은 `python scripts/extract_ssol_icons.py ../figma-ssol src/assets/img/3d`, 활력징후 초록 배경은 `python scripts/make_green_bg.py ../figma-ssol/design-p2 src/assets/img/bg-green.png` 로 다시 만들 수 있습니다.
